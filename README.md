# GRAMO — Precision Motion Technology

Gotowy front-end strony w stylu High-Tech / Deep-Tech.

## Szybki start
1. Zainstaluj Node.js 20+.
2. W folderze projektu uruchom `npm install`.
3. Uruchom `npm run dev`.

Uwaga: ten pakiet jest przygotowany jako nowoczesny prototyp wdrożeniowy. Dla produkcyjnego Next.js można przenieść komponent do `app/page.jsx` i CSS do `app/globals.css`.

## Vercel
Najprościej: GitHub → import repozytorium w Vercel → Deploy → podłącz domenę.
